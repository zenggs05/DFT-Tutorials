# DFT-Tutorials：第一原理計算チュートリアル & スクリプト集

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE) [![Docs](https://img.shields.io/badge/docs-online-blue.svg)](https://zenggs05.github.io/DFT-Tutorials/)

**VASP・Gaussian・CP2K・OpenMX** を対象とした、密度汎関数理論（DFT）計算の実践的なチュートリアル集です（本文は簡体字中国語、各章に英語サブタイトル付き）。

- インストール／コンパイル、入力ファイル、収束テスト、構造最適化
- バンド構造・状態密度、ハイブリッド汎関数、DFT+U、スピン軌道相互作用
- 表面・吸着、遷移状態（NEB / IRC）、フォノン、第一原理分子動力学
- TD-DFT 励起状態、溶媒和、NBO・電荷解析、電子輸送（NEGF）など

各章には実行可能な入力例、キーワードごとの解説、エラー対処法、参考文献、そして Python / Bash の補助スクリプトが付属します。

- 📂 章立ての一覧：README_en.md（英語）／[README.md](README.md)（中国語）
