# DFT-Tutorials: tutoriais e scripts de cálculos de primeiros princípios

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE) [![Docs](https://img.shields.io/badge/docs-online-blue.svg)](https://zenggs05.github.io/DFT-Tutorials/)

Coleção prática de tutoriais de **teoria do funcional da densidade (DFT)** para **VASP, Gaussian, CP2K e OpenMX** (texto em chinês simplificado, com subtítulos em inglês em cada capítulo).

- Instalação/compilação, arquivos de entrada, testes de convergência, otimização de geometria
- Estrutura de bandas e DOS, funcionais híbridos, DFT+U, acoplamento spin-órbita
- Superfícies e adsorção, estados de transição (NEB / IRC), fônons, dinâmica molecular ab initio
- Estados excitados TD-DFT, solvatação, análise NBO/cargas, transporte eletrônico (NEGF) e mais

Cada capítulo traz entradas prontas para rodar, explicação de cada palavra-chave, solução de erros comuns, referências e scripts auxiliares em Python/Bash.

- 📖 Versão online (com busca): <https://zenggs05.github.io/DFT-Tutorials/>
- 📂 Índice de capítulos: README_en.md (inglês) / [README.md](README.md) (chinês)
- 🔗 Repositórios relacionados no GitHub: [Resources/github-repos.md](Resources/github-repos.md)

Não incluímos POTCARs do VASP nem código-fonte/binários de software comercial. Tutoriais e scripts sob [MIT License](LICENSE) (`CP2K/data/` pertence ao projeto CP2K, GPL). Se for útil, deixe uma ⭐!
