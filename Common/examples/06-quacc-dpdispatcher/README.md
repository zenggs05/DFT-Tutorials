# 示例 06-quacc-dpdispatcher（Common example）

本目录是 Common 板块第 6 章的配套示例。各文件的用途与参数说明见文件头部注释。

|---|---|
| [dpdisp_encut_scan.py](dpdisp_encut_scan.py) | .py |

## 使用方法

1. 将整个目录复制到计算集群的工作目录；
2. 阅读各文件头部注释，按需修改路径、核数与计算参数；
3. 脚本类文件可用 `python <脚本> -h` 或 `bash -n <脚本>` 先行检查。
