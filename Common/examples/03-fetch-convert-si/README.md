# 示例 03-fetch-convert-si（Common example）

本目录是 Common 板块第 3 章的配套示例。各文件的用途与参数说明见文件头部注释。

## 文件列表

| 文件 | 类型 |
|---|---|
| [check_symmetry.py](check_symmetry.py) | .py |
| [cif_to_all.py](cif_to_all.py) | .py |
| [fetch_mp_structure.py](fetch_mp_structure.py) | .py |
| [Si.cif](Si.cif) | .cif |

## 使用方法

1. 将整个目录复制到计算集群的工作目录；
2. 阅读各文件头部注释，按需修改路径、核数与计算参数；
3. 脚本类文件可用 `python <脚本> -h` 或 `bash -n <脚本>` 先行检查。
