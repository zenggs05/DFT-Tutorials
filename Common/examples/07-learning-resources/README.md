# 示例 07-learning-resources：资源书签与学习打卡表

## 目的

把[第7章](../../tutorials/07-learning-path.md)中分散的学习资源整理成两份可以直接打印或复制到笔记软件里的清单：一份是只含链接的书签列表，一份是 12 周学习计划的打卡表（含每次计算前的自检清单）。

## 文件说明

| 文件 | 说明 |
|---|---|
| [resources.md](resources.md) | 官方文档、在线书与课程、awesome 列表、论坛与中文社区、MLIP 比较网站、本仓库入口的链接清单 |
| [study_checklist.md](study_checklist.md) | 12 周学习打卡表 + 每次计算的自检清单 |

## 运行步骤

本目录不需要运行任何程序：

1. 把 `study_checklist.md` 复制到自己的笔记目录（或 fork 后在 GitHub 上直接编辑，勾选 `[x]`）；
2. 每周完成后，在“记录”一栏写下产出文件的路径（例如 `~/work/si_conv/encut.png`）；
3. 浏览器书签可以从 `resources.md` 中逐条添加，或用任意 Markdown 转 HTML 工具生成书签页。

## 预期结果 / 如何检查

- 12 周后你应当拥有：一套收敛测试报告、一组能带/DOS 图、一个表面或吸附模型、一个 NEB 能垒、一份可复现的文献复现目录；
- 自检清单中的每一项都能在你的计算记录中找到对应证据。

## 注意事项

- 链接截至 2026-11 有效；若失效，请在仓库 Issues 中反馈。
- 列出的第三方仓库只供链接和阅读，未声明许可证的仓库不能复制其代码或文字。
